Integracje API: programy w firmie zaczynają wymieniać dane

Jeżeli te same informacje wpisujesz do dwóch albo trzech systemów, często nie potrzebujesz nowego programu. Potrzebujesz połączenia między tymi, które już masz.

Co to jest integracja API w praktyce?

API to sposób, w jaki programy mogą przekazywać sobie dane. Dla użytkownika efekt jest prosty: nowy klient z formularza pojawia się w CRM-ie, zaakceptowane zlecenie tworzy dokument, płatność zmienia status, a faktura dostaje dane bez ponownego wpisywania.

Co można połączyć?

  • formularz internetowy z CRM-em
  • CRM z kalendarzem i systemem zleceń
  • system zleceń z księgowością lub fakturami
  • sklep z magazynem, Allegro i hurtownią
  • własną aplikację z usługą zewnętrzną
  • system raportowy z kilkoma źródłami danych

Co jeśli program nie ma API?

Czasem dostępny jest eksport CSV, XML, plik na serwerze albo webhook. Da się zbudować połączenie także na takich mechanizmach. Jeżeli system jest całkowicie zamknięty, trzeba ocenić, czy integracja jest bezpieczna i opłacalna, zamiast obiecywać „na pewno się da”.

Dwukierunkowa synchronizacja czy jeden kierunek?

Dla każdego rodzaju danych warto wskazać system nadrzędny. Przykładowo CRM przechowuje dane klienta, a księgowość je pobiera. Przy synchronizacji dwukierunkowej ustalamy także, która zmiana ma pierwszeństwo i jak rozstrzygać konflikty.

Co z błędami?

Integracja powinna zapisywać historię, identyfikatory operacji i błędy. Jeżeli faktura nie przejdzie albo zewnętrzne API jest chwilowo niedostępne, użytkownik powinien wiedzieć, co nie zostało wykonane i co można bezpiecznie ponowić.

Kontrola poprawności integracji

W firmie ważniejsza od samego przesłania danych jest kontrola: logi, walidacja, obsługa duplikatów, powiadomienia i możliwość odtworzenia tego, co wydarzyło się z konkretnym rekordem.

Integracje e-commerce

Sklepy internetowe są jednym z obszarów, w których robię to szczególnie często: sklep z księgowością, Allegro, BaseLinker i hurtownie. Ta sama technika działa jednak w procesach usługowych i B2B.

Ile kosztuje integracja?

Najbardziej wpływa na cenę jakość dokumentacji API, liczba operacji, wymagany kierunek synchronizacji i obsługa wyjątków. Punkt startowy znajdziesz w cenniku.

Bezpieczeństwo i dostęp do API

Klucze API i tokeny nie powinny być wpisane w kod strony ani przesyłane między pracownikami. Integracja przechowuje je po stronie serwera, a uprawnienia powinny być ograniczone do operacji, których naprawdę potrzebuje. Jeżeli dostawca obsługuje osobne konto techniczne, warto z niego korzystać.

Limity i zmiany po stronie dostawcy

Projekt uwzględnia limity zapytań, wygasanie dostępu i zmiany wersji API. Operacje mogą trafiać do kolejki, a nieudane przesłania są zapisywane do sprawdzenia lub bezpiecznego ponowienia.

Najczęstsze pytania

Czy potrzebuję dostępu administratora?

Zależy od systemu. Często wystarczy możliwość utworzenia aplikacji API lub tokenu z odpowiednimi uprawnieniami. Najpierw sprawdzam dokumentację, zanim proszę o szeroki dostęp.

Czy integracja może działać w czasie rzeczywistym?

Tak, jeśli system udostępnia webhooki lub odpowiednie API. W innych przypadkach dane mogą być synchronizowane cyklicznie, np. co kilka minut.

Co jeśli API przestanie odpowiadać?

Operacja powinna trafić do kolejki lub zostać oznaczona jako błąd, a nie zniknąć. To jeden z powodów, dla których monitoring jest częścią poważniejszej integracji.
